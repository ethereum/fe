A trait can declare an associated shape, `shape Step`, which each implementation gives (`shape Step = (own usize, mut? T)`), and a method can return it: `fn at(mut? self) -> Self::Step`. A shape is named at a mode, `D::Step<ref>` or `D::Step<mut>`, and a `mut?` item's own signature names it at the item's mode. A shape's accesses are at most its mode, so an implementation writes `mut?` rather than `mut`. Generic code passes a value of an associated shape on whole: it returns it, or passes it to a parameter of the same shape (`_ s: D::Step<ref>`), at most once, and a bound can take it, as in `F: Fn(D::Step<ref>) -> bool`.
