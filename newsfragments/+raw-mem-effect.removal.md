The `std::evm::RawMem` effect is removed. EVM memory is local to a call, so raw memory access needs only an `unsafe` context, not an effect: use `core::abi::store_word` and the new `core::abi::load_word` for words, and `*p = byte` for single bytes. `RawOps` now extends only `RawStorage`, and functions such as `encode_packed`, `keccak_packed`, `Packed`'s builders and `bytes_from_words` no longer declare `uses (mem: mut RawMem)`.
