Added `unsafe { .. }` blocks. Dereferencing a raw pointer or calling an `unsafe fn` is now an error outside an `unsafe` block or `unsafe fn`. A struct or enum field can be declared `unsafe` when safe code relies on its value, such as a buffer's length: reading it is safe, but setting or mutating it requires `unsafe`. A dependency's `unsafe` code can only be used if `fe.toml` trusts the dependency with `allow_unsafe = true`; your own ingots, `core` and `std` are always trusted.
