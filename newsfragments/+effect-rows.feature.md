Traits can declare associated effect rows and result spaces. `uses E` in a trait is a row that each implementation fills (`uses E = (store: mut Store)`, or nothing), its methods use it with `uses E`, and generic code requires an implementor's row with `uses T::E`, which callers then provide. `space S` is an associated result space for projections (`fn at(self, c) -> ref Self::Item @S`), so a collection over storage yields storage places. A `with` installing a provider that names storage now needs that place to lie in one of the function's own effects, raw storage authority, or an `unsafe` block.
