Traits can declare associated effect rows and result spaces. `uses E` in a trait is a row that each implementation fills (`uses E = (store: mut Store)`, or nothing), its methods use it with `uses E`, and generic code requires an implementor's row with `uses T::E`, which callers then provide. `space S` is an associated result space for projections (`fn at(self, c) -> ref Self::Item @S`), so a collection over storage yields storage places. A `uses (storage: Field(T))` effect is the authority over the storage a handle of type `T` names, taken from the handle argument, and a `with` providing a storage handle now needs the function's own authority over it, or an `unsafe` block.
