A string literal longer than 31 bytes whose context does not fix its type is now a `DynString` instead of an error, so `let reason = "a long revert reason ..."` works and a long literal can be passed to a generic `Encode` parameter. Short literals are still `String<N>`. On the EVM, a `DynString` literal of 96 bytes or more is copied into memory from the contract code rather than stored a word at a time.
