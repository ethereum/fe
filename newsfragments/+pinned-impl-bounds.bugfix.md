A `Pinned` implementation applies only to the instances its bounds admit, everywhere: a bounded `impl<P: X> Pinned for Cell<P>` no longer makes the contract layout number a `Cell<B>` field as transient while lowering keeps it in storage, where it overwrote another field. A blanket implementation, also one in a dependency, no longer makes every type state-only, and `@transient` on a type it does not pin is rejected.
