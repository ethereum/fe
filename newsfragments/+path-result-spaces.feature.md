Result-space contracts can name sub-places: `-> mut T @self.value`, `@self.pair.0`, `@self.cells[_]`, `@d.f` for an effect's place, and `space S = self[_]` in an implementation. A sub-place lies where its path leads: into a pinned type's space, into an entry's collection's `SPACE`, and in memory for a packed lane, whose grants are memory copies. `Mutex::value`/`value_mut` declare `@self.value`. A path naming no part of its root's type is error 3-0067.
