Dependencies must be trusted before their `unsafe` code may run. A dependency entry in `fe.toml` trusts the dependency with `allow_unsafe = true`; the ingots being compiled, workspace members, `core` and `std` are trusted, and a trusted dependency's own `allow_unsafe` entries extend trust further. Only use counts: an untrusted dependency's safe API needs no trust, and the compiler reports the call in your code that first reaches an untrusted dependency's `unsafe` block or `unsafe fn` body.
