A memory array or memory pointer of a pinned type is state-only, so `MemArray<SCell>`, `MemArray<TSlot<T>>` and `MemArray<StorageMap<K, V>>` are rejected instead of lowering their elements as storage or transient slots at their memory addresses, which let safe code with no effects write contract state. A generic body instantiated so that one of its memory values is state-only is rejected at the instance (16-0010).
