A trait can take a parameter list as a `shape` parameter and spread it into a method: `trait Apply<shape A> { fn apply(self, ..A) -> u256 }`, implemented as `impl Apply<(own u256, ref u256)> for Adder { fn apply(self, _ a: own u256, _ b: u256) -> u256 { .. } }` and called with one argument for each parameter, `adder.apply(1, x)`. `Fn` and `FnMut` are such traits: `Fn(own A, B) -> R` is `Fn<(own A, B), Out = R>`, and `-> _` leaves the result open, as in `F: FnMut(u256) -> _`.
