The instance limit (16-0016) now ends recursion that grows its generic arguments in more than one way, which made exponentially many instances and hung `fe check`, and recursion that grows a const argument (`f<{ N + 1 }>`), which panicked; a call that reaches a rejected instance is rejected with it. Nesting depth counts type nesting levels, so a non-recursive call with 32 levels of pairs is no longer rejected.
