A struct field whose type is an associated type (`T::Out`) or a contract now takes the storage slots its value does: such a contract field failed to compile with `ContractFieldSpanMismatch`, and `SolArray` elements holding one overlapped. A `SolArray` element that is not packed into lanes, including a `SolPacked` value wider than 128 bits, is stepped by the slots its storage layout takes, which the new const intrinsic `core::intrinsic::storage_slots<T>()` gives.
