A driver names the collection it runs over, `type Base`, and each position yields a step, `shape Step`: `Enumerate<D>`'s is `(own usize, D::Step)`. A loop's pattern binds the step as a `let` binds a projection's result, so `for (i, (j, x)) in xs.enumerate().enumerate()` copies what it names, and a closure a driver calls takes the step whole: `xs.enumerate().map(|(i, x)| i as u256 * x)`. The chain methods (`enumerate`, `take`, `skip`, `step_by`, `filter` and `map`) are `Driver`'s own, and generic code bounds a driver's step, `D: Driver<Base = C, Step<ref> = ref u256>`.
