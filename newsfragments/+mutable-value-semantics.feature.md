Fe now has mutable value semantics. References are no longer values: a parameter is a view (`x: T`), exclusive (`x: mut T`) or owned (`x: own T`); a `let h = mut p.x` or `ref p.x` binding is a scoped access; and a function returning `ref T`, `mut T` or a shape such as `(usize, mut T)` or `Option<mut T>` is a projection, which may `yield` once and run code after the caller is done with the access (a slide), as in `let mut tmp = self.get(k); yield mut tmp; self.set(k, tmp)`. A new access checker replaces the borrow checker: two open accesses to overlapping places conflict unless both read, an access ends at its last use, a projection's session reserves the places its arguments name until the caller's last use of what it yielded, storage collections such as `StorageMap` are owners at their storage places, so `balances[k]` is a path under `balances` that the checker sees with a dynamic key, and an external call conflicts with every open storage access. A view parameter takes a scalar or handle by copy (a snapshot; `core::marker::Snapshot` marks types such as `Address`) and views every other value in place, `Copy` arrays and structs included. Types marked `#[view]`, such as `MemSlice`, are only ever seen through a view. See `docs/architecture/access-checker.md`.
