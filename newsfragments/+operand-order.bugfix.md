A variable used as a call argument, an aggregate field or an operator operand is now read where it appears, before the operands after it run: `add(x, bump(mut x))`, `(x, bump(mut x))` and `x + bump(mut x)` read `x` before `bump` resets it, including when `x` is an effect. Passing a variable by value or as a view and then using it in a later argument, as in `take(bag, bag.n())` or `inspect(bag, reset(mut bag))`, is now rejected.
