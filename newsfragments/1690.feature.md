Added `core::sort` with sorting and searching after Solady's `LibSort`, generic over both the container and the element: `sort`, `insertion_sort`, `heap_sort`, `reverse`, `swap`, `is_sorted`, `is_sorted_unique`, `lower_bound`, `binary_search` and `dedup_sorted` work on any `SeqMut` whose items implement `Ord`. `sort` uses insertion sort for up to 16 elements and heapsort above, so it is `O(n log n)` for every input. `core::seq::Seq` reads a sequence by index and `core::seq::SeqMut` replaces its elements; both are implemented for fixed arrays, `MemSlice`, `MemArray` and `std::abi::MemVec`. `std::evm::Address` implements `Ord` by numeric value, so signer lists can be sorted and checked with `is_sorted_unique`.
