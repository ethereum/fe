Added `core::sort` with sorting and searching after Solady's `LibSort`, generic over both the container and the element: `sort`, `insertion_sort`, `heap_sort`, `reverse`, `swap`, `is_sorted`, `is_sorted_unique`, `lower_bound`, `binary_search` and `dedup_sorted` work on any collection indexed by position, through `Index<usize>` (and `IndexMut<usize>` to reorder) and the new `core::ops::Len`, whose elements implement `Ord`. `sort` uses insertion sort for up to 16 elements and heapsort above, so it is `O(n log n)` for every input. Fixed arrays, `MemSlice`, `MemArray` and `std::abi::MemVec` qualify: arrays now implement `Index`, `IndexMut` and `Len` for generic code, and `MemVec` indexes through decoded temporaries. `std::evm::Address` implements `Ord` by numeric value, so signer lists can be sorted and checked with `is_sorted_unique`.
