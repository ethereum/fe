Added closures, such as `|x| x + 1` or `|acc: own u256, x: u256| -> u256 { acc + x }`. A closure can be passed to any function that takes a callable, including `fold`, `any`, `count` and `find` on collections and the `filter` and `map` loop adapters (`for x in xs.filter(|x| x % 2 == 0)`). Your own functions accept one with a bound such as `F: Fn(u256) -> bool` and call it with `f.call(x)`; a closure passed to such a function can leave out its parameter types, which come from the bound. A closure can also be bound to a variable, stored in a struct or tuple, and used in contract code, where its body can use the contract's storage and other effects; a generic function that calls a closure declares `uses F::E` so that its callers provide those effects. A closure captures the values it uses by copy or move and cannot modify them, so state is passed through parameters and results instead, as `fold` does. Closures cannot be used in constant contexts, and cannot capture a `ref` or `mut` binding, or a view parameter of a non-`Copy` type.
