Safe code can no longer make all-zero values of types zero is no value of. `core::marker::Clearable` excludes types with `unsafe` fields, `MemArray::new_zeroed` and `MemArray::zero` require `T: Clearable`, and contract state (fields, code fields and collection entries) rejects a type with `unsafe` fields (3-0069), since state starts zeroed. `std::evm::Evm`'s seal is an `unsafe` field, so neither a zeroed array nor a contract field forges the EVM capability, and a zeroed `FixedMemBuffer`, `DynString`, `Bytes` or `DynArray` no longer breaks its invariant.
