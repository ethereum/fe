Decoding a memory input through a public entry point that takes the input's length from its caller (`Decode::decode_from_bounded`, `decode_from_prechecked_head`, `decode_frame_from`, `decode_msg_field_from`, `decode_field_from_prechecked_head`) no longer copies bytes from past the input when that length exceeds it; the copy is bounded by the input itself and fails instead. `ByteInput::copy_to_memory_unchecked` must now be safe for any source range.
