A `recv` arm's variant path is resolved once, where the arm is written, with the bare names of a named `recv M { .. }` block naming `M`'s variants. Previously `self::V { .. }` passed the block check and then failed with "`V` is not found", and an arm naming no variant also reported its field bindings as undefined variables. A fieldless variant can now be matched by its path, like `M::U -> u256 { .. }`, in either kind of `recv` block.
