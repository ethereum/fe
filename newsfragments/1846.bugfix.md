A `recv` arm's variant path is resolved once, where the arm is written, with the bare names of a named `recv M { .. }` block naming `M`'s variants. Previously `self::V { .. }` passed the block check and then failed with "`V` is not found", and an arm naming no variant also reported its field bindings as undefined variables. A fieldless variant can now be matched by its path, like `M::U -> u256 { .. }`, in either kind of `recv` block. The block checks the path as any other path is checked where it's written: it reports a segment that isn't visible, a generic variant named without its arguments, like `G { value }` for `G<T>`, and an unmet requirement of a type the path names, and in a bare `recv { .. }` block a path that names nothing, like `Gone -> u256 { .. }`, which wasn't reported before.
