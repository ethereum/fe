`IndexMut::index_mut` now takes `mut self`, so `a[i] = v` and `a[i] += v` through a trait-lowered index require a writable base, such as a `var` binding or a `mut` parameter. Raw array pointers no longer implement `Index` or `IndexMut`; index the pointee in an `unsafe` block instead, as in `unsafe { (*p)[i] }`.
