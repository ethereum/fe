A projection that yields a value, such as `fn low(self) -> ref u32 { self.word.downcast_truncate() }`, no longer fails with an internal access checking error: the value is held in a temporary of the projection's frame, which the yield grants. A `mut` projection may now yield a value the same way, with the usual warning that writes are discarded when no code after the yield stores the temporary back; a place still has to be named `mut` to be granted.
