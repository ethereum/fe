The borrow checker now checks each function against the signatures of the functions it calls, instead of inferring summaries from their bodies. A borrow a call returns comes from the callee's `self` receiver when it has one, and otherwise from every argument that holds a borrow; a `mut` argument that can hold borrows may keep any of the call's other borrows. Changing a function's body no longer changes whether its callers compile, and borrow checking is much faster. Memory views such as `MemSlice` implement the new `core::marker::Borrows` marker and borrow the owner they were derived from, so `a.as_slice()` keeps `a` from being mutated while the slice is live. See `docs/architecture/borrow-checker.md`.
