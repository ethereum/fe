Layout holes are removed: a const parameter can no longer default to `_`, `_` is no longer a const generic argument, and functions no longer take hidden layout parameters. A storage value's slot is the slot of the contract field that holds it, so a type no longer needs a slot parameter, and arrays of storage collections such as `[StorageMap<K, V>; N]` are supported, each element at its own slot. Migration: remove `= _` defaults and `_` arguments, and drop any const parameter that only stood for a slot.
