`ref` and `mut` are no longer allowed in type positions (struct fields, generic arguments, `let` annotations and `self: ref Self`), so structs can no longer hold borrows, and the `core::marker::Borrows` marker is removed. A `MemSpan` can no longer be kept past its owner's next mutation: `MemBuffer::span`, `MemArray::as_slice`, `MemSlice::slice`, `head` and `tail` return `ref` projections, `MemSlice` no longer implements `Copy` and has no public constructor, `try_slice` returns the `(start, len)` range it validated, and `split_at` is replaced by `head`/`tail`. `Seq` is replaced by `Collection`. `Index::index` returns `ref Self::Output`, and `Index`/`IndexMut` declare effect rows and a result space. `Mutex::try_lock` returns `bool`, with the protected value exposed through `value`/`value_mut`; `HashTreeRoot::hash_tree_root` and `EncodePacked` for spans take a span view with a separate `start` and `len`; and the ABI decoder is first-order, taking its input in each call.
